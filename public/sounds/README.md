# Focus chimes

Drop custom chimes here to replace the built-in synthesized bell:

| File            | Plays when                    |
| --------------- | ----------------------------- |
| `work-end.mp3`  | a focus session finishes      |
| `break-end.mp3` | a short or long break ends    |

Keep each under ~3 seconds and around −16 LUFS so they sit comfortably over
music. Missing files fall back to the built-in tone automatically.
